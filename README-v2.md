# Hook Management System (HMS)

> **Repository Description:**  
> *Automated Python pipeline & GUI for syncing Suno AI music stems, transient beat markers, and Google Flow video shots into DaVinci Resolve via FCP 7 XML.*

**Version:** `v2.5.0`  
**Target Platform:** DaVinci Resolve Free / Studio (FCP 7 `xmeml v5` Protocol)  
**Audio / Generative Stack:** Suno v5/v6, Librosa STFT, Google Flow / Veo 3.1  

---

## 📌 Overview

The **Hook Management System (HMS)** is an automated audiovisual production pipeline designed to bridge AI audio engines (Suno), generative video models (Google Flow / Veo 3.1), and non-linear video editors (DaVinci Resolve). 

HMS eliminates manual timeline alignment and resolves DaVinci Resolve's FCPXML 1.9 import bugs (such as MP4 freeze-frame holds and sub-second audio offset drops) by generating strict, track-isolated **FCP 7 XML (`xmeml v5`)** sequence files with embedded transient beat markers.

---

## 🛠️ Key Features

- **Master GUI Control Panel (`hms_master_gui.py`):** Unified desktop application with system revision tracking (`v2.5.0`) and live logging to `C:\renders\hms_workflow.log`.
- **Sub-Second Audio Trimming:** Automatically cuts master WAV files down to the exact hook section starting at frame 0 (`<track_slug>_master_trimmed.wav`) to ensure 100% reliable audio placement in DaVinci Resolve.
- **Track-Aware File Isolation:** Naming conventions incorporate song slugs (e.g., `dear_me`, `paper_dolls`) to prevent overwriting metadata across multiple production runs.
- **Librosa & Text Transient Engine:** Parses custom `thebeats.txt` transient maps or calculates onset envelopes dynamically, embedding color-coded blue marker pins directly on the timeline audio track.
- **FCP 7 XML Schema Enforcement:** Bypasses FCPXML spine-nesting bugs by utilizing discrete `<track>` nodes for video and audio streams.

## 🚀 Quickstart & Setup

### 1. Installation
Clone the repository and install required Python packages:
```cmd
git clone <your-repository-url>
cd hook-management-system
pip install -r requirements.txt
```

### 2. File Organization
Place track assets according to the HMS folder convention:
- **Video Clips:** `C:\renders\<track_slug>\shot1.mp4` through `shot5.mp4`
- **Master Audio:** `C:\audio\<track_slug>_master.wav`
- **Transient Data (Optional):** `C:\renders\output\<track_slug>_thebeats.txt` & `<track_slug>_hooktimestamp.txt`

### 3. Execution
Launch the GUI application:
```cmd
python hms_master_gui.py
```
Click **🚀 EXECUTE FULL AUTOMATED PIPELINE**. This will automatically rename shots, trim audio to frame 0, load transient maps, and generate `C:\renders\<track_slug>\<track_slug>_hook_timeline.xml`.

## ⚙️ Standard Operating Procedure (SOP) for DaVinci Resolve

1. **Configure Project Settings:** Open DaVinci Resolve, press **Shift + 9**, and set **Timeline Frame Rate** to **24 fps**.
2. **Import Timeline:** Press **Ctrl + Shift + I** (or select **File > Import > Timeline...**) and choose `C:\renders\<track_slug>\<track_slug>_hook_timeline.xml`.
3. **Enable Snapping:** Press **N** on the Edit Page so kinetic Text+ titles and cuts magnetically snap to the blue drum transient markers.

*For detailed troubleshooting and advanced styling options, refer to `docs/davinci_import_sop.md`.*

## 🏷️ System Revision Tracking

All generated XML timelines embed the active system revision (`v2.5.0`) in three locations for full auditability:
1. **XML Root Header:** `<!-- Generated by Hook Management System (HMS) Master GUI Engine [v2.5.0] -->`
2. **Timeline Sequence Name:** `<track_title> Hook Video [v2.5.0]`
3. **Frame 0 Marker:** `SYSTEM_REV: v2.5.0`
