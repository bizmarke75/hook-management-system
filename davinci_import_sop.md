# DaVinci Resolve Import SOP (Standard Operating Procedure)

**System Version:** `v2.8.0`  
**Protocol:** FCP 7 XML (`xmeml v5`) Interoperability Standard  

---

## 🎯 Purpose

This document outlines the standard protocol for importing generated AI music video timelines, master audio clips, and transient beat markers into **DaVinci Resolve Free and Studio** without media dropouts, freeze frames, or audio sync drift.

---

## 📋 Pre-Import Checklist

Before launching DaVinci Resolve, verify that the following files exist in your local workspace:

1. **Video Shots Directory (`C:\renders\<track_slug>\`):**
   - `shot1.mp4`, `shot2.mp4`, `shot3.mp4`, `shot4.mp4` (or `shotN.mp4`)
2. **Master Audio WAV (`C:\audio\`):**
   - `<track_slug>_master.wav` (e.g. `this_is_my_obituary_acoustic_master.wav`)
3. **Trimmed Audio WAV (`C:\audio\`):**
   - `<track_slug>_master_trimmed.wav` (automatically generated by HMS)
4. **Timeline XML (`C:\renders\<track_slug>\`):**
   - `<track_slug>_hook_timeline.xml` (automatically generated by HMS)

---

## 🎬 Step-by-Step DaVinci Resolve Import Procedure

1. **Launch DaVinci Resolve** and create a new project (e.g. `This Is My Obituary (Acoustic)`).
2. **Configure Project Frame Rate:**
   - Press **Shift + 9** to open **Project Settings**.
   - Under **Master Settings ➔ Timeline Format**, set **Timeline Frame Rate** to **24 fps**.
3. **Import Timeline File:**
   - Press **Ctrl + Shift + I** (or go to **File ➔ Import ➔ Timeline...**).
   - Navigate to `C:\renders\<track_slug>\<track_slug>_hook_timeline.xml` and click **Open**.
4. **Confirm Load Settings:**
   - Leave default settings checked (*Automatically import source clips into media pool*).
   - Click **OK**.

---

## 🧲 Timeline Editing & Beat Snapping

1. Press **`N`** on your keyboard to enable magnetic timeline snapping.
2. Observe the blue marker flags along the audio track (`A1`). These mark exact 95.7 BPM beat transients.
3. Use **`Ctrl + R`** (Windows) / **`Cmd + R`** (Mac) to open **Retime Controls** and snap speed points to marker flags.
